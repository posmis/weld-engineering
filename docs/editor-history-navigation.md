# История проекта и навигация

Этап продолжает редактор из [editor-movement.md](editor-movement.md). Результат: можно отменять/повторять правки проекта, переносить камеру и масштабировать схему, сохраняя согласованность числового ввода, расчётного снимка и признака сохранения.

## Реализовано

- Undo/redo для координат, ширин, добавления/удаления участков, нагрузок, точки приложения и названия. Восстанавливаются расчётный результат и предупреждение о происхождении сохранённого снимка вместе с входными данными, без нового вызова Rust.
- До 100 действий в памяти; новый/открытый/импортированный проект очищает историю. Набор в одном поле объединяется до смены фокуса. Один перенос мышью — одно действие. Escape восстанавливает исходные данные и ветку redo, включая сохранённый результат. Неконечные числовые черновики не клонируются через JSON и не превращаются в null.
- Возврат к сохранённому снимку возвращает чистое состояние. Настройки редактора и навигация не записываются в историю проекта. SQLite-ревизии остаются неизменяемыми, схема базы v2 и схема JSON проекта v1 прежние.
- Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z работают вне текстовых полей. В полях сохраняется встроенное редактирование текста; кнопки приложения доступны для отмены операции проекта. История недоступна при запросе backend, модальном диалоге и активном переносе.
- Колесо масштабирует относительно курсора с одинаковым XY-масштабом; кнопки ± — относительно центра. Диапазон 1–10000% вписанного вида. Крайние/неконечные преобразования отклоняются. Passive wheel браузера заменён обработчиком, который подавляет стандартный zoom/scroll только на схеме.
- Средняя кнопка или режим «Панорамирование» перемещают камеру. Escape отменяет жест, «Вписать схему» возвращает все участки в кадр. Во время переноса шва масштаб фиксирован и колесо не меняет его.

## Границы

История и камера не восстанавливаются после перезапуска; сохраняются сами проекты и настройки шага/привязок. Это операции редактора; расчётные формулы, области применимости и статус недоступной нормативной прочности не изменены. Полные ГОСТы, книги и OCR не входят в Git/CI.

Следующий содержательный этап расчётной части — документированный номинальный изгиб/кручение в Rust с проверкой обусловленности, равновесия, независимых эталонов и выводом распределения в GUI. Нормативная оценка прочности требует отдельной проверки метода и источников согласно development-handoff.md.
