# Материалы проекта

[Пользовательские карточки и применимость](custom-materials.md) реализованы: отдельные основной/наплавленный металл, явные свойства/диапазоны/источники, отсутствие свойства — unknown/null. Данные сохраняются в JSON/SQLite/PDF проекта; Windows 42126360576 / source 6fceea6 пройден: 95 Rust/API и 100 frontend ×3, установленный EXE/restart/PDF. Это не проверенный нормативный каталог и не глобальная библиотека/поиск материалов.

Не импортировано ни одного нормативного свойства. Предстоят верифицированные source_standard/edition/source_clause, product_form/delivery_condition/heat_treatment, роли/условия и пригодность к конкретному методу прочности. Интерполяция допускается только по обоснованному методу, сейчас отсутствует. Пользовательские значения не становятся нормативными даже при ссылке на ГОСТ.
