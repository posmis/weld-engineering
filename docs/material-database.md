# Материалы — проект модели

Не импортировано ни одного свойства материала. Будущая запись: designation, source_standard/edition, product_form, delivery_condition, heat_treatment, thickness_interval, temperature_interval, property_name, value, unit, source_clause/table, verification_status. NULL означает неизвестное. Интерполяция допускается только по обоснованному методу. Основной и наплавленный металл — разные записи. Пользовательские свойства маркируются custom и не становятся нормативными. Нет базы SQLite или реализованного поиска материалов.
