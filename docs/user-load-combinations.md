Переработка UI остаётся на конец; добавлен только ввод/вывод новой функции.

## Метод и область

Каждая сила исходного случая j масштабируется отдельно: Fji,new = γj·Fji. Точка P каждой силы сохраняется, включая явно выбранный centroid. Свободный момент Mj масштабируется тем же γj. Для текущего центра сечения C:

FΣ = Σ γj·Fji; MΣ,C = Σ γj·(Mj + Σ (Pji−C)×Fji).

Сервис материализует отдельные силы и суммирует только свободные моменты (компенсированное суммирование). Существующий расчёт переносит каждую силу через r×F и вычисляет номинальные напряжения. Положения сил не усредняются; изгибающие/крутящие моменты не теряются. Нормативные коэффициенты/допустимость совместного действия не назначаются. Пользователь обязан выбрать физически совместимые источники; независимые альтернативные случаи сами по себе не обязаны действовать одновременно. Список исходных случаев без этой явной операции по-прежнему считается независимым.

Коэффициенты конечные, могут быть отрицательными/нулевыми. Начальные единицы — редактируемый пример, не рекомендация. Ноль исключает вклад, но источник остаётся в аудите и валидируется. Должен быть хотя бы один ненулевой коэффициент; полная компенсация ненулевых вкладов допускается. Нет автоматического перебора нормативных сочетаний, envelopes сочетаний, динамики, усталости или подбора. Вложенные сочетания не принимаются; в диалоге перечислены только обычные случаи.

Независимые эталоны:

- A: масса 10 kg, g=(0,0,−10), a=(2,0,0) m/s² → F=(−20,0,−100) N; P=(10,20,30) mm; свободный M=(10,20,30) N·mm.
- B: F=(0,5,0) N; P=(−10,0,20) mm; свободный M=(1,2,3) N·mm.
- Для C=(0,0,0) и 2A−3B: FΣ=(−40,−15,−200) N; свободный M=(17,34,51) N·mm; моменты сил (−4000,800,800)+(300,0,150), итог MΣ,C=(−3683,834,1001) N·mm.
- Центральные A:Fz=600 N и B:Fz=−200 N; 2A−3B → 1800 N, при Aсеч=200 mm² → σz=9 MPa. Прочность не оценивается.
- Свободные моменты 10¹⁶, 1, −10¹⁶ N·mm с коэффициентами 1 дают 1 N·mm: малый вклад сохраняется компенсацией суммы.

Лимиты: до 32 случаев вместе с новым, 32 уникальных исходных случаев в DTO, до 64 ненулевых сил в материализованном сочетании, документ до 1 MiB. Исходные нулевые силы не занимают места в выходной коллекции, но сохраняются в снимках. Повторные/неизвестные id, неконечные факторы, переполнение/исчезновение ненулевого произведения в ноль или субнормальный диапазон отклоняются. Лимит 64 не обходится сведением сил с разными P в одну.

## Контракт и снимки

`CombinationRequest`={schema_version:1,project,title,terms:[{case_id,factor}]}. Tauri `create_load_combination(request)` и POST `/api/v1/cases/combine` возвращают Project с добавленным активным LoadCase и без результата этого нового случая. Существующие случаи и их результаты сохраняются. Геометрия не меняется. Для единственного legacy-проекта сначала создать нагрузочный случай командой копирования; API требует casebook. Метод: `user-linear-load-combination-v1`.

Optional `LoadCase.combination` хранит method_id и sources:[{case_id,title,factor,load:{forces?,force_n,couple_n_mm,application}}]. Это замороженные исходные нагрузки, включая m/g/a/P, без рекурсивных проектов/старых результатов. Материализованные силы не получают ложный mass source: коэффициент может быть отрицательным, поэтому исходная масса хранится в снимке источника, а выходная сила — обычная сила с отдельным id.

Изменение/удаление исходного случая не обновляет уже созданный снимок. Источники не обязаны оставаться в живом casebook. Геометрия общая: её изменение сбрасывает результаты, сохраняя сочетание и исходные точки/centroid-семантику. Validator повторяет вывод нагрузок по сохранённым источникам; несовпадение с силами/моментом сочетания → combination_load_mismatch. Это проверка согласованности, не подлинности внешнего JSON. Формат проекта остаётся v1 с optional полем; старому строгому клиенту нужно обновление.

В свойствах нагрузок нажать «Сочетание нагрузок», задать название и коэффициенты, создать. Операция целиком отменяется одним Undo/Redo. Закрытие/нативное закрытие окна отменяет диалог; поздний ответ не применяется к изменившемуся или закрытому проекту. Фоновый workbench/горячие клавиши изменения проекта заблокированы на время диалога.

Правка силы, её имени/P/источника или свободного момента превращает активное сочетание в обычный случай, убирая недостоверную связь с формулой; это предупреждение показано в свойствах. Undo возвращает модель и сохранённые результаты. Название самого случая можно менять без изменения нагрузок. Копирование случая сохраняет замороженную модель; новый снимок не ссылается динамически на исходный.

PDF печатает метод, коэффициенты, id/названия источников, исходные силы/точки/массу/ускорения и свободные моменты. JSON-вложение содержит полный снимок и фактический результат. strength_status по-прежнему unsupported_calculation, validation_status — not_independently_validated.
