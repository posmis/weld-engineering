# PDF-отчёт

«Отчёт PDF» в верхней панели открывает обычное окно сохранения Windows. Отмена не меняет проект. Можно сформировать отчёт и до расчёта: отсутствие результата указано явно. Отчёт пока русскоязычный при любом языке интерфейса.

Перед формированием Rust проверяет весь проект и все снимки. PDF содержит схему общей геометрии, координаты и эффективную ширину, каждый независимый случай, силы/моменты/точку приложения, геометрические характеристики, компоненты номинальных напряжений, диагностику, исходные engine_version/method_id/schema и неполноту сводки. Снимки не пересчитываются и не получают новую версию ядра. Числа форматируются для печати с 10 значащими цифрами; полный JSON прикреплён к PDF как weld-project.json. Для обратного импорта извлеките вложение PDF-просмотрщиком.

JavaScript выполняет только пагинацию и отображение Rust-результатов. Геометрия рисунка — условное изображение, его толщина не задаёт a. Компоненты не объявляются локальными напряжениями горла. Документ всегда указывает отсутствие нормативной проверки прочности и независимой инженерной валидации. PDF не является подписанным протоколом или подтверждением подлинности импортированных снимков.

Кириллица/греческие символы: свободный Noto Sans под SIL OFL 1.1, лицензия и происхождение в src/assets. Не поддерживаемые шрифтом символы отображаются как ?, оригинальные имена сохраняются во вложенном JSON. Нет загрузки шрифта из интернета при работе приложения. Исходные ГОСТы/книги в отчёт и артефакты не включаются.

Нативная команда save_pdf_report принимает PDF до 16 MiB, пользователь выбирает файл; Rust записывает байты и возвращает фактический путь, который показывается в строке состояния. Отмена возвращает null. Windows CI проверяет настоящий диалог/запись, PDF unit test проверяет читаемость, кириллицу в метаданных, многостраничность и наличие вложения. Артефакт CI содержит только собственный отчёт синтетического тестового проекта.
