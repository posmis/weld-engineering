# Номинальные изгиб и кручение линейного сечения

Метод `elastic-line-traction-v1` — собственный математический вывод из принятого аффинного поля и равновесия. Это не нормативный метод сопротивления сварных соединений. Плоские прямолинейные участки имеют заданную пользователем постоянную эффективную ширину, dA=a ds. Модель не определяет катет, провар, локальные концентрации, напряжения в ориентированном горле, допускаемые значения и pass/fail. Полярное поле ниже не является решением задачи Сен-Венана для произвольного сечения и не учитывает депланацию/различия жёсткостей.

## Вывод и знаки

Все координаты x,y ниже — относительно центра группы C. Оси правосторонние, плоскость сечения XY, положительная нормаль +Z. Нагрузка сначала переносится из P в C: M_C=M+(P−C)×F. Площадь A, Ix=∫y²dA, Iy=∫x²dA, Ixy=∫xy dA, J=Ix+Iy; ∫x dA=∫y dA=0.

Принимаем поле (τx,τy,σz)=(Fx/A−k y, Fy/A+k x, Fz/A+bx x+by y). Из Mz=∫(xτy−yτx)dA следует k=Mz/J. Из Mx=∫yσz dA и My=−∫xσz dA:

```
[Iy  Ixy] [bx] = [-My]
[Ixy Ix ] [by]   [ Mx]
```

Следовательно, bx=(−My Ix−Mx Ixy)/(Ix Iy−Ixy²), by=(Mx Iy+My Ixy)/(Ix Iy−Ixy²). Код решает нормализованную систему без образования размерного произведения Ix·Iy. Для несимметричных групп Ixy не отбрасывается. N/mm²=MPa. Компоненты подписаны в глобальных осях; сведение в критерий разрушения не производится.

На каждом участке координаты и компоненты линейны по s/L. Поэтому минимум/максимум σz находятся в концах; евклидова норма вектора (τx,τy) выпукла, её максимум тоже достигается в одном из концов. Возвращаются значения обоих концов каждого участка, диапазон σz и max|τ|. Это экстремумы принятого поля, не оценка реальных концентраций.

## Применимость и численная политика

При точно нулевых трёх моментах application service сохраняет прежний `uniform-direct-traction-v1` и единственный вектор F/A. При ненулевом моменте возвращает распределение; единственный `traction_mpa` отсутствует, чтобы переменное поле не выглядело равномерным.

Изгиб (любой ненулевой Mx/My) требует положительно определённой и достаточно обусловленной матрицы K. Используется rcond=λmin/λmax; после деления K на max(Ix,Iy), λmax находится через hypot, λmin/λmax=det(K)/λmax². Условие допуска rcond>sqrt(f64::EPSILON), примерно 1.49e−8, — численная политика ограничения усиления округления, не геометрический допуск и не нормативный коэффициент. При нарушении возвращается unsupported_loading, причина ill_conditioned_section, геометрия сохраняется, напряжений нет. Даже совместимый изгиб по одной оси для вырожденного линейного сечения в этой реализации консервативно отклоняется. Прямая нагрузка и полярное кручение не требуют невырожденной K; для кручения нужен J>0.

Все полученные силы/моменты проверяются интегрированием поля по исходным участкам. Для силы используется среднее конечных значений; для r×t — правило Симпсона, точное для полинома степени 2. Для ненулевой заданной компоненты ошибка нормируется на её абсолютное значение; большая взаимно компенсирующаяся нагрузка не должна скрыть потерянную малую компоненту. Для нулевой компоненты используется интеграл верхней оценки абсолютных слагаемых. При обоих нулях ошибка равна нулю. Максимум по шести компонентам должен быть ≤sqrt(EPSILON). Переполнение, недопустимое деление, потерянные из-за underflow нагрузки и несоблюдение равновесия дают numerical_range, без частичного успешного поля. Политика консервативна: нагрузки ниже разрешения больших компенсирующихся напряжений могут быть отклонены.

Программные проверки и остаток равновесия не заменяют независимую инженерную валидацию. Статус not_independently_validated сохраняется; прочность всегда unsupported_calculation. Правила исключения пересечений/наложений исходных участков не меняются.

## Контракт и сохранение

У CalculationResult добавлено опциональное поле distribution. Оно содержит segments (в том же порядке, что input_snapshot.segments; start_mpa/end_mpa — [τx,τy,σz]), normal_range_mpa, max_shear_mpa, bending_rcond (null без изгиба), equilibrium_error. Для старых результатов поле отсутствует и при сериализации не добавляется. JSON schema_version входа/проекта остаётся 1, версия SQLite — 2. Новый reader открывает прежние результаты без пересчёта; старый reader с deny_unknown_fields отклонит новый результат с distribution, поэтому новые распределения следует открывать актуальной версией приложения.

Структурная валидация сохранённого поля проверяет число участков, конечность, допустимость численных диагностик, согласованность статуса/метода и экстремумов. Она не пересчитывает историческую механику и не удостоверяет происхождение внешнего JSON. Сохраняются input_snapshot, engine_version, method_id и исходные значения поля. GUI показывает выбранный участок, профиль компоненты, таблицу концов и глобальные экстремумы; редактирование удаляет текущий результат, Undo восстанавливает соответствующий снимок.

## Аналитические эталоны

Два участка x=−50…50, y=±20, a=2 mm: A=400 mm², Ix=160000 mm⁴, Iy=400·10000/12 mm⁴, Ixy=0. При Fz=600 N и Mx=160000 N·mm получаем σz=1.5+y MPa: диапазон −18.5…21.5 MPa. При My=Iy N·mm и остальных нулях σz=−x. При Mz=J N·mm поле (τx,τy)=(−y,x) MPa, max|τ|=sqrt(20²+50²) MPa.

Другие проверки: несимметричная группа с Ixy≠0 и независимая трёхточечная квадратура Гаусса для всех шести результантов; поворот/трансляция; смена знака нагрузки и удвоение ширины; масштабирование геометрии с согласованным изменением F и M; вырожденные и почти коллинеарные группы; overflow/underflow; эквивалентность эксцентриситета и пары в C; прежние и новые snapshots SQLite/JSON и повреждённые поля. Результаты Windows-прогона фиксируются после его фактического выполнения.
