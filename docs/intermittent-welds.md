# Прерывистые швы

В свойствах выбранного шва раскройте «Прерывистый шов». Задайте длину сваренного участка, шаг между началами и количество. «Заменить выбранный шов» создаёт реальные отдельные линейные элементы вдоль исходного направления. По умолчанию предлагаются 20/40 mm и 3 участка; это редактируемые геометрические значения, **не нормативные рекомендации**. Если они не помещаются, операция отклоняется без изменения модели.

Все участки имеют исходную эффективную ширину a. Число 1–256, суммарно в проекте не более 256 участков; при числе больше одного шаг строго больше длины. Последний конец не может выходить за исходный отрезок. Сохраняются нагрузки/точка приложения, удаляются результаты всех нагрузочных случаев. Один Undo восстанавливает исходную геометрию и все снимки. В SQLite/JSON/PDF записываются обычные явные элементы; зависимости от скрытого шаблона нет.

Генерация и проверка выполняются в Rust, включая конечность координат, нулевую длину, точные пересечения/наложения и лимиты. Исходная модель должна проходить общий geometry validator. Нормативные минимумы длины/шага, концевые эффекты, старт/кратер и технологическая пригодность не оцениваются. Промежутки не входят в L/A/I; пример: 3×20 mm при a=2 mm дают A=120 mm², Fz=600 N → номинальное σz=5 MPa.

Tauri: generate_intermittent(request). REST: POST /api/v1/geometry/intermittent. Запрос IntermittentInput: input (CalculationInput), segment_index (с нуля), weld_length_mm, pitch_mm, count. Ответ — новый CalculationInput. Изменения проекта и история остаются ответственностью вызывающего приложения.

Подготовлены Windows unit/HTTP/UI tests, включая наклонный обратный шов и Undo полного набора случаев. Текущий результат CI ещё ожидается.
