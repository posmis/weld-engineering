## Объективные зависимости

Сейчас нет проверенного применимого общего нормативного метода прочности машинных сварных соединений и полного набора материалов/коэффициентов. Образовательные номинальные формулы не заменяют его. Строительные СП/СНиП из найденных пособий не переносятся автоматически на машиностроение. Геометрические ГОСТы не задают универсальную оценку прочности. FKM найден библиографически, полный легально доступный текст для проверки не получен. Исследование источников продолжается по [research-continuation.md](research-continuation.md).

После подтверждения источника каждый нормативный модуль требует: собственную реализацию с идентификатором версии метода; явные границы применимости/отсутствующих данных; независимые численные примеры, включая отказы; проверку инженером; traceability до пункта/редакции без копирования публикаций в Git. Только после этого открываются нормативный verdict и автоматический подбор.

Не реализованные модули не подменены заглушками с успешным результатом. strength_status остаётся unsupported_calculation. ГОСТы/книги и полные извлечённые тексты остаются исключительно в локальной среде.
