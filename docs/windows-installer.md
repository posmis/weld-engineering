# Установка Windows

GitHub Actions создаёт NSIS `Weld Engineering_0.1.0_x64-setup.exe` в артефакте weld-engineering-windows-x64. Для запуска установленной программы не нужны Node.js, Rust или исходники. Целевая ОС Windows 10/11 x64; отдельная приёмка на пользовательских Windows 10/11 ещё не выполнена, автоматические испытания идут на windows-2022.

Установщик работает для текущего пользователя. Запустите setup.exe, затем Weld Engineering из меню «Пуск». WebView2 используется как runtime: при его отсутствии установщик может скачать официальный Microsoft bootstrapper, поэтому требуется интернет. Отдельная полностью офлайн-установка WebView2 пока не включена. Программа и установщик не подписаны цифровым сертификатом; это предварительная версия 0.1.0, не аттестованный нормативный пакет.

Удаление через настройки приложений Windows удаляет программу. Сохранённые SQLite-проекты/настройки в пользовательском AppData по умолчанию сохраняются. Перед переносом на другой компьютер экспортируйте JSON либо собственный PDF с JSON-вложением. API — отдельный weld-api.exe в том же CI artifact, он не запускается автоматически при установке/старте desktop.

Для разработки из исходников по-прежнему служит start.bat. Сборка установщика на Windows: `npm ci`, затем `npm run tauri build -- --ci` из apps/desktop. Версии Rust/Node и C++ Build Tools см. getting-started.md. Во время сборки Tauri получает NSIS tooling; полные ГОСТы/книги не являются ресурсами сборки/установки.

CI устанавливает в изолированную директорию своего пользователя, сверяет hash установленного EXE с собранным, запускает на нём полный native UI/SQLite/PDF workflow, удаляет программу и проверяет сохранность базы. Текущий первый результат installer CI пока ожидается. Публикация GitHub release не выполняется; доступен только артефакт проверки с retention 7 дней.
