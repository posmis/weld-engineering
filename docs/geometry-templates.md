# Построение группы швов по размерам

«Шаблон группы» в верхней панели открывает параметры и предварительный просмотр. Доступны прямоугольник (4 участка), два параллельных горизонтальных шва (2), П-образная группа (3, открыта к +Y) и Г-образная (2, левая и верхняя стороны, Γ). Это осевые линейные группы, **не типы соединений по ГОСТ и не нормативные сечения горла**.

Ширина W и высота H задают габарит, a — постоянную эффективную ширину всех участков. X/Y — центр габарита, который для открытых П/Г-групп не совпадает с центром эффективного сечения. Расчётный C определяется Rust-ядром после явного расчёта; предпросмотр его не подменяет. Параметры 100/40/2 mm при открытии — редактируемый пример, не нормативные минимумы или рекомендации.

Предпросмотр создаётся тем же Rust-сервисом, что возвращает данные для применения. После правки параметров прежний preview нельзя применить: кнопка доступна только для ответа на актуальный запрос. Неконечные/неположительные размеры, переполнение и схлопывание координат на большом смещении отклоняются. Exact intersection validator общий с ручным вводом.

«Заменить геометрию» заменяет все существующие участки на просмотренный набор. Название проекта, нагрузки, точки приложения и все нагрузочные случаи остаются; их рабочие результаты сбрасываются. Один Undo восстанавливает прежнюю геометрию и снимки всех случаев. До применения Cancel/Escape/закрытие окна отменяют только preview, не меняя проекта. Незаполненная нагрузка также сохраняется как черновик и не превращается в ноль.

После применения это обычные независимые элементы с численными координатами. Параметрическая связь с W/H не хранится; последующее редактирование осуществляется существующими свойствами/мышью. Камера вписывает новый набор; прежняя панель результатов закрывается, освобождая место для редактирования. Её можно открыть из дерева, новый расчёт открывает её автоматически. Поворот, распространение ограничений на сопряжённые концы и общий параметрический CAD этим инструментом не реализуются.

## Сервисный контракт

`geometry_templates::generate(GeometryTemplateRequest)` и Tauri `generate_group_template(request)` возвращают GeometryTemplateResult с schema_version=1 и segments. Запрос содержит schema_version=1, kind (`rectangle`, `parallel`, `u_shape`, `l_shape`), положительные width_mm/height_mm/effective_width_mm и конечный origin_mm=[x,y]. Неизвестные поля отклоняются. Старые координаты/нагрузки не передаются в генератор, поэтому он не может неявно изменить нагрузки или преобразовать NaN черновика в JSON null.

REST: POST /api/v1/geometry/template, тот же request/response и общий application service. Схема добавлена в OpenAPI; ранее существовавшие endpoints и форматы проектов/SQLite не изменены.

Независимые геометрические ориентиры: прямоугольник 100×40 при a=2 даёт L=280 mm, A=560 mm²; для origin=[10,-5] C=[10,-5], Ix=181333,333333… mm⁴, Iy=733333,333333… mm⁴. П-группа тех же размеров: A=360 mm², C=[0,-100/9] mm; Γ-группа: A=280 mm², C=[-100/7,100/7] mm. Эти значения выведены интегрированием заданных линейных элементов, не из нормативных коэффициентов.

Подготовлены unit/HTTP/frontend и установленный Windows native сценарий с preview, применением, пакетным расчётом и Undo. Текущий прогон ещё ожидается. Linux builds/tests не выполняются по требованиям проекта. Наличие шаблона не означает прочностную или технологическую пригодность выбранной группы.
