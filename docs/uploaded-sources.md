У первых двух документов пункт 1 описывает геометрию соединений из сталей и сплавов на железоникелевой/никелевой основе, исключая трубопроводные соединения по ГОСТ 16037. Их таблицы не перенесены в расчётную базу.

Для лазерного документа пункт 1 описывает лазерную сварку металлических материалов; разделы 5, 8, 9, 13 дают направления исследования качества, WPS, проверки процедуры и контроля. Наличие ссылок на EN ISO 13919-1/-2, 15609-4, 15614-11 не доказывает существование либо актуальность соответствующих ГОСТ. Следует проверить приложение ДА и официальные карточки каждого документа отдельно.

В извлечённом тексте 86416.pdf отдельный лист поправки не идентифицирован. Это не доказывает отсутствие поправки: нужна визуальная сверка и отдельная официальная публикация. Актуальный статус всех трёх стандартов на дату применения остаётся непроверенным, поскольку официальные реестры недоступны. Статус provided_document не равен verified_current_standard.

Следующие необходимые источники: официальные карточки этих трёх стандартов с действующими изменениями/поправками; поправка к ГОСТ EN 1011-6-2025; обоснованная методика статической прочности машиностроительных сварных соединений с коэффициентами и эталонными примерами. Историческая редакция 2017 нужна позже только для сравнения изменений, не для новых расчётов.
