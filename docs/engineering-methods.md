## Независимый вывод геометрии
Для прямого участка p(t)=p0+t(p1−p0), t∈[0,1], равномерная заданная ширина эффективного сечения a: dA=a L dt. Отсюда A=aL, центр участка (p0+p1)/2. Центр группы — сумма A_i c_i / сумма A_i.

Относительно центра группы: Ix=Σ A_i[(cy_i−cy)²+dy_i²/12], Iy=Σ A_i[(cx_i−cx)²+dx_i²/12], Ixy=Σ A_i[(cx_i−cx)(cy_i−cy)+dx_i dy_i/12], J=Ix+Iy. Коэффициент 1/12 получается интегрированием (t−1/2)² от 0 до 1. Это линейная модель сечения, без собственного поперечного момента конечной ширины; она не заменяет точную геометрию объёмного шва. Ширина a задаётся пользователем; не выводится из катета/провара и не подтверждается ГОСТ. Пересекающиеся/совпадающие участки суммируются как заданные элементы, не как объединение площадей; вызывающая сторона обязана исключить двойной счёт.

## Перенос нагрузки
Правосторонние оси. Сила F приложена в P, исходная свободная пара M. Момент относительно O: M_O=M+(P−O)×F. N и mm дают N·mm. Математический результат не является критерием разрушения.

Коэффициенты безопасности, допускаемые напряжения, эффективные длины, эквивалентные напряжения и размеры по ГОСТ не реализованы. Для каждого будущего метода требуется источник, точная редакция, область применимости, формулы, коэффициенты и независимые эталоны.


## Центральная прямая нагрузка: номинальные компоненты
Реализована centred_direct_traction. По равновесию F_i=∫_A t_i dA; при явно принятой равномерной номинальной тяге t_i=F_i/A. В XY-сечении компоненты (Fx/A,Fy/A) — сдвиговые, Fz/A — нормальная. Знак определяется правосторонними осями. 1 N/mm²=10⁶ N/m²=1 MPa. A берётся из заданных эффективных линейных элементов; определение этой площади остаётся ответственностью вызывающего кода/выбранной будущей методики.

Ограничения: сила задана в центре сечения, свободных моментов нет; статическая равномерная номинальная модель, без локальных концентраций, эксцентриситета, градиента напряжений, усталости, давления и критерия разрушения. Это не универсальная формула эквивалентного напряжения. Сложение компонентов в критерий прочности не реализовано; допустимые напряжения и запас не возвращаются. Для иных нагрузок функция неприменима. Источник для сравнения: NPTEL, курс 112107090, лекция 25, разделы 25.2–25.3; формула независимо выведена выше, нормативные коэффициенты из лекции не используются.
