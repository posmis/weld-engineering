# Независимые нагрузочные случаи

До 32 случаев используют общую геометрию. В дереве выберите «Нагрузки»: список выбирает текущий случай, «Копировать случай» создаёт новый с такими же нагрузками и без результата. Имя редактируется отдельно. Последний случай удалить нельзя. «Рассчитать» обрабатывает текущий, «Рассчитать все» — весь набор через Rust application service.

Изменение геометрии удаляет результаты всех случаев; изменение нагрузки — только текущего. Переключение восстанавливает его собственные нагрузки и снимок без автоматического пересчёта. Undo/redo охватывает набор. Esc при отмене жеста восстанавливает все исходные снимки. Активный случай сохраняется в ревизии, поэтому его переключение меняет документ.

В нижней панели раскрывается «Сводка случаев»: минимум/максимум σz и максимум √(τx²+τy²) с определяющим случаем, номером участка и концом 1/2. Экстремумы берутся Rust-сервисом из сохранённых конечных значений линейного распределения. При равенстве выбирается первый в порядке случаев/участков/концов. Сводка явно неполна при нерассчитанном, неподдерживаемом или численно отказавшем случае; отказ одного случая не скрывает остальные. Это независимые случаи, **не сочетания нагрузок, не усталостный спектр, не проверка прочности**.

Project schema 1 расширена опциональным `casebook` (`schema_version`, `active_id`, `cases`). Старые документы без поля читаются и записываются без добавления поля. Старые версии программы с deny_unknown_fields отклонят новый документ с casebook; используйте актуальную версию. Каждый случай содержит id, title, force_n, couple_n_mm, application, nullable last_calculation. Основные input/last_calculation — точная проекция активного случая. Несовпадения, дубли id, неверные снимки/нагрузки отклоняются. Лимит JSON по-прежнему 1 MiB, поэтому максимально подробный набор может достигнуть лимита раньше 32 случаев.

Команды `calculate_load_cases(project)` и `summarize_load_cases(project)` адаптируют общие функции `cases::calculate_cases` и `cases::summarize_cases`. Сводка пересобирается из снимков, механика при открытии не пересчитывается. Исходные результаты не заменяются новым engine_version.

Проверка текущего изменения: Windows CI; локальная Linux-сборка/тесты не выполняются по требованиям проекта. Конкретный результат CI будет записан после выполнения.
