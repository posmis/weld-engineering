# Численная верификация

Подготовленные независимые аналитические эталоны: горизонтальный участок L=100 mm, a=2 mm: A=200 mm², центр (50,0), Ix=0, Iy=200·100²/12 mm⁴. Два параллельных участка x=[−50,50], y=±20, a=2: A=400, Ix=160000, Iy=400·100²/12, Ixy=0. Перенос F=(0,10,0) N из P=(100,0,0) mm к началу даёт Mz=1000 N·mm.

Тесты также проверяют смену знака нагрузки, перенос центра при трансляции, сохранение центральных моментов при трансляции, отклонение нулевой длины, неположительной ширины и NaN. Набор не является полной квалификацией численного метода. Требуются масштабные/поворотные инварианты, экстремальные диапазоны и независимый инженерный обзор.

**Исполнение:** тесты не запускались. Причина: доступная машина Linux, требования разрешают первоначальное тестирование только Windows. Windows workflow подготовлен; публикация файлов и его выполнение ещё не проводились.


Дополнительный эталон: L=100 mm, a=2 mm, A=200 mm², F=(400,-200,600) N в центре сечения. Подписанные номинальные компоненты равны (2,-1,3) MPa из независимого равновесия. При удвоении a компоненты уменьшаются вдвое. Добавлены три теста для direct traction; все семь тестов ожидают запуска Windows, ни один прогон не заявляется.
