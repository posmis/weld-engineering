# Полная матрица разработки и приёмки

Источник требований: product-requirements.md. Ни одна строка planned не является обещанием, что функциональность уже существует. Начальное состояние зафиксировано перед первым push.

| Область | Текущее состояние | Что реализовать | Проверка завершения |
|---|---|---|---|
| Единицы и численная надёжность | Начальный Rust-код, тесты не выполнены | Конверсии, допуски, обусловленность, конечность промежуточных результатов | Windows tests, аналитические эталоны и инварианты |
| Плоская геометрия | Линейные интегралы заданы | Пересечения, непрерывные/прерывистые швы, ориентация, проверка применимости | Независимые площади/центры/моменты, трансляции и повороты |
| 3D нагрузка | Перенос момента задан | Load cases, направления, масса/ускорение, преобразования CAD | Проверки знаков, единиц и равновесия |
| Номинальная механика | F/A для центральной нагрузки задан | Изгиб/кручение/эксцентриситет только в документированной модели | Вывод формул, равновесие, эталоны, отказ для сингулярности |
| Реестр стандартов | Метаданные трёх действующих ГОСТ | Все части EN 1011, поправки, применимость, обновление/замена | Официальные карточки, дата проверки, транзакции, ревалидация |
| Стандартная геометрия | Не реализована | Кириллические типы стык/тавр/угол/нахлёст с привязкой к процессу и редакции | Сверка полных таблиц, границы толщин, точные ссылки; права на данные |
| Материалы | Проект схемы | Основной/наплавленный металл, толщина/температура, unknown/custom | Источники каждой величины, тесты границ и отсутствующих свойств |
| Статическая прочность | UnsupportedMethod | Проверенный метод для определённой области машинных деталей | Независимые численные примеры, весь путь service→GUI→отчёт |
| Коэффициенты | Не реализованы | Нормативные/пользовательские/динамические множители, аудит overrides | Проверка отсутствия двойного учёта, полный factor chain |
| Подбор и оптимизация | Не реализованы | Ограничения, причины отказа, несколько кандидатов, Pareto/стоимость | Нет допустимых кандидатов при нарушении обязательного ограничения |
| Лазер | Исследование источника | Отдельные геометрия/провар/доступность луча/качество | Не приравнивать провар к несущей толщине; unsupported при отсутствии метода |
| Усталость | Не реализована | Классификация деталей, спектры, кривые, повреждение по проверенному методу | Независимые примеры; недостаточные данные блокируют расчёт |
| Давление и герметичность | Не реализованы | Раздельные прочность, устойчивость/деформации и приёмочные испытания | Статический pass не означает герметичность или pressure compliance |
| Производство/качество | Не реализованы | WPS/WPQR, персонал, контроль, дефекты, тепловые требования | Источники каждого требования; расчёт не доказывает качество изготовления |
| Application service | Не реализован | Serde contracts, versioning, structured errors, лимиты | Integration tests без GUI, неизвестные версии отклоняются |
| SQLite и проекты | Не реализованы | Миграции, материалы/методы/источники, неизменяемые snapshots | Round trip, rollback, повреждённый ввод, сохранение старого результата |
| Windows desktop | Не реализован | Tauri 2, React/TS/CSS, русский UI, English resources, темы | Windows build; реальное сообщение GUI↔Rust; не имитация результата |
| 2D рабочее поле | Не реализовано | Сечение и отдельный layout, числовое/мышиное редактирование, нагрузки | Диаграмма совпадает с данными, воспроизводимый ввод |
| Результаты | Не реализованы | Verified pass/fail, insufficient, unsupported, not validated | Ни один unsupported результат не отображается зелёным pass |
| Отчёты PDF | Не реализованы | Исходные данные, версии, формулы, подстановка, ссылки, рисунки | Открываемый PDF с кириллицей и воспроизводимыми значениями |
| REST/OpenAPI | Только проект документа | Versioned local API, validation, limits, маршруты | Проверка request/response по реальному OpenAPI и smoke tests |
| Inventor | Только проект документа | Стабильные CAD-независимые схемы, C# guide | Примеры единиц/координат; add-in сейчас НЕ реализовывать |
| Сборки/релизы | Подготовлен Windows CI | Pin toolchain/dependencies, Windows packaging, воспроизводимость | Фактический успешный Windows CI; публикация релиза только по разрешению |

## Условие «модуль завершён»
Область, обоснованные формулы/источники, единицы, автоматические тесты, независимые эталоны, ограничения, ошибочные входы, воспроизводимость, реальный GUI-результат и инженерный отчёт должны быть проверены вместе. Для библиотечного промежуточного результата явно указывать, что GUI/PDF ещё отсутствуют. Не заменять исходные критерии этой сокращённой матрицей.
