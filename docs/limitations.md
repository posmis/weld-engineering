# Ограничения текущей реализации

Windows-клиент, Rust service и SQLite-проекты реализованы и проверены в ограниченном сценарии. Фактические результаты: [iteration-01.md](iteration-01.md). Это ещё не нормативный прочностной MVP.

Реализованы: линейная геометрия прямых участков постоянной эффективной ширины, центроид и моменты площади; перенос нагрузки; номинальные подписанные F/A при нулевом результирующем моменте; редактирование чисел и SVG layout; язык RU/EN и темы; неизменяемые SQLite revisions, versioned JSON. После изменения исходных данных старый результат убирается из рабочей копии, а сохранённый снимок остаётся неизменным.

Геометрическая модель не является объединением полос конечной ширины и не учитывает собственный поперечный момент ширины. Ненулевой момент блокирует F/A. Пространственные группы, изгиб/кручение и локальные напряжения не реализованы. Точная рациональная проверка пересечений не устраняет ограничений f64 при вычислении интегральных свойств.

Нет нормативной геометрии по ГОСТ, сопротивлений, допускаемых напряжений, safety factors, выбора материала, pass/fail, автоматического подбора, оптимизации, PDF, REST/OpenAPI runtime, давления/герметичности, усталости или оценки качества/лазерной прочности. Официальные статусы трёх ГОСТ проверены, но это не верификация параметров и методик. Полные нормативные публикации и книги остаются только в среде, вне Git и артефактов приложения.

Рабочая копия защищена диалогом при замене проекта и закрытии; drag концов и отмена жеста реализованы (iteration-02.md). Нет общей истории undo/redo и стандартного поперечного сечения соединения. Imported JSON не проверяется на подлинность — только на формат, числовую/структурную согласованность. Сохранённый исходный результат не переаттестуется автоматически при открытии.

Проверено на Windows runner windows-2022; испытаний на отдельной Windows 10 машине и проверки всех файловых диалогов пока нет. Есть EXE без установщика/подписи, нужен WebView2 Runtime. Первая итерация и исправления frontend-тестов слиты в main; текущее развитие описано в iteration-02.md. Среда и GitHub release не публиковались.
