# Ограничения текущей реализации

Точный статус этапов: [completion-status.md](completion-status.md). Программа — ограниченный математический инструмент, а не завершённый нормативный прочностной пакет. Последние фактические Windows-проверки перечислены в [testing.md](testing.md); наличие исходников не означает прохождение CI.

Реализованы линейные эффективные сечения из прямых XY-участков постоянной ширины, их площадь/центр/Ix/Iy/Ixy/J, перенос силы через r×F, номинальные F/A и ограниченная аффинная модель изгиба/полярного кручения. Есть независимые случаи, частичная сводка компонентов и генератор явных прерывистых участков. Промежутки не участвуют в сечении. Численные/геометрические отказы не заменяются нулями.

[Идеализированное сечение по двум катетам](idealized-fillet-section.md) выводит a только для прямоугольного треугольника с прямой гранью. Провар, вогнутость, произвольный угол и нормативная проверка размеров не учитываются. Сохранённые катеты должны согласовываться с a; старые приложения без поддержки поля section не откроют такие проекты.

Модель не является объединением полос конечной ширины и не учитывает собственный поперечный момент ширины. Наложения/пересечения/T-стыки запрещены, допускаются общие концы. Для изгиба требуется невырожденная достаточно обусловленная матрица сечения; совместимые нагрузки на сингулярном сечении отдельно не решаются. Полярное кручение не является общим решением Сен-Венана. Нет локальных напряжений горла, пластичности, концентраций, пространственных/кривых швов, усталости и нелинейного расчёта. Подробнее — [nominal-bending-torsion.md](nominal-bending-torsion.md).

[Нагрузка от массы](mass-acceleration-loads.md) — эквивалентная F=m(g−a) для заданного поступательного ускорения в глобальных осях. P задаёт центр масс; автоматического расчёта центра масс тела, вращательной инерции, модального/временного отклика и динамических коэффициентов нет. Это не подтверждает применимость статической идеализации к конкретному движению.

[Пользовательское сочетание](user-load-combinations.md) — снимок линейной суммы нагрузок с заданными коэффициентами. Это не назначение нормативных сочетаний, не живая связь между случаями и не проверка допустимости их совместного действия. Вложенные сочетания не поддерживаются.

Нет нормативной геометрии по ГОСТ, проверенных сопротивлений/допускаемых напряжений и свойств материалов, safety factors, нормативного pass/fail, автоматического подбора/оптимизации, проверки давления/герметичности, WPS/WPQR и приёмки качества/лазерной прочности. Официальный статус стандарта не означает верификацию его параметров. Подставлять строительные сопротивления для общего машиностроения нельзя. strength_status всегда unsupported_calculation, validation_status всегда not_independently_validated.

CAD-окно поддерживает дерево/свойства, числовое/мышиное/клавиатурное редактирование, перенос целого шва, привязки/шаг, undo/redo, zoom/pan, отдельный dock результатов, RU/EN и темы. Добавлены символы Fxy/Fz/Mz, численные свободные моменты и карты подписанных номинальных σz/τx/τy. Цвет не является допускаемым напряжением или оценкой прочности. Нет редактора нормативного поперечного сечения соединения и полноценного 3D CAD. Масштаб рисунка и выбор объекта не являются проверкой размеров по ГОСТ.

SQLite хранит неизменяемые ревизии. Изменение геометрии удаляет рабочие результаты всех случаев, изменение нагрузки — текущего; сохранённые ревизии не изменяются. Открытие снимка не пересчитывает и не переаттестует его. Импорт проверяется на формат/согласованность, не на подлинность. Ограничение JSON 1 MiB может сработать раньше предельных 32 случаев × 256 участков. Старое приложение не прочитает новый casebook: нужен актуальный reader.

PDF содержит исходные значения/формулы/снимки/версии и вложенный JSON, но не является подписанным протоколом. Пока русскоязычный, числа в печати округляются, неподдерживаемые шрифтом символы заменяются ?. REST запускается отдельным Windows-процессом только на loopback с токеном и лимитами; каталогов нормативных материалов и endpoints несуществующих расчётов нет. Inventor add-in по исходному заданию не создаётся; предоставлены guide и самостоятельный C# transport client.

Испытания выполняются на windows-2022. Отдельные Windows 10/11 машины, все пользовательские сценарии, обновление/цифровая подпись и независимая инженерная валидация ещё не приняты. Нет оснований объявлять программу готовой к ответственным расчётам прочности.

Полные ГОСТы, книги, сканы/OCR и переводы остаются вне Git/CI artifacts/отчётов. В артефактах могут быть только собственные отчёты и изображения искусственного тестового проекта.

[Пользовательские материалы](custom-materials.md) хранятся в проекте и проверяются только на структуру/однозначность диапазонов. Значения не независимо проверены и не включают материалозависимую механику или нормативную прочность; свойства вне контекста неизвестны. Верифицированного каталога и глобального поиска материалов нет.
