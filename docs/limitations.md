# Ограничения и фактический статус

Реализовано: исходный Rust-код математической основы и аналитические тесты. Независимая валидация и выполнение тестов ещё не состоялись. Это не готовый продукт и не MVP для инженерного допуска.

Не реализовано: desktop GUI, Tauri commands/application service, Serde/JSON проектов, SQLite, нормативные расчёты, материал-база, автоподбор, оптимизация, PDF, REST/OpenAPI, локализация, интерактивное редактирование, усталость, давление, герметичность, качество/лазерная сварка. Ни один ГОСТ не проверен. Нормативная часть фазы 0 заблокирована доступом к источникам.

Математическая геометрия: только плоские прямолинейные участки с постоянной заданной эффективной шириной, без геометрического объединения пересечений и собственного поперечного момента ширины. Пространственные группы и напряжения не вычисляются. При близких к машинной точности длинах/крайних масштабах возможны потери точности; нет заявления об устойчивости во всём диапазоне f64.

Репозиторий не опубликован и не отправлен в GitHub. Сборка Windows и результаты CI не получены. Исходная облачная Linux-среда не заменяет Windows development/test runner.

Дополнение: реализован исходный код номинального F/A для центральной нагрузки; не прошёл Windows-испытания. Текст поправки найден у вторичного распространителя, официальная библиография совпадает; официальный полный лист ещё не сверялся. См. research-continuation.md.
