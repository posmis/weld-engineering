# Итерация 02 — редактор схемы и поведение настольного окна

## Проблема и результат
Обычный запуск через start.bat использует Tauri dev; стандартное меню WebView2 могло показывать браузерные команды и инспектор страницы. Теперь default context menu отключено через native WebView2 settings, а конфигурация окна по умолчанию отключает devtools. Frontend также предотвращает стандартный contextmenu и браузерные команды F12, Ctrl+Shift+I/J/C, Ctrl+U и перезагрузку F5/Ctrl+R. Ctrl+C/Ctrl+V и обычное редактирование остаются доступными.

ПКМ по схеме открывает собственное меню редактора: добавить участок в выбранной точке, удалить выбранный участок, закрыть меню. Добавляемый участок имеет редактируемые стартовые размеры L=100 mm, a=2 mm — это пользовательские начальные данные, не нормативный подбор.

## Редактирование
Концы прямых участков перетаскиваются мышью с pointer capture. На время жеста viewport фиксируется, чтобы auto-fit не менял масштаб под курсором. После завершения схема снова подгоняется к геометрии. Escape отменяет жест, восстанавливая исходный проект и результат, а не только координаты. Координаты не округляются до скрытой сетки. При завершённом редактировании прежний расчёт сбрасывается.

X и Y теперь используют одинаковый масштаб: предыдущая реализация могла искажать пропорции. Доступно числовое редактирование и управление сфокусированным концом стрелками (1 mm, с Shift 10 mm). Масштабирование SVG — преобразование ввода/экранных координат; инженерные свойства и напряжения по-прежнему вычисляет Rust.

## Несохранённые данные
Состояние рабочей копии сравнивается с последней сохранённой/открытой ревизией. Создание проекта, открытие ревизии, импорт и нативное закрытие окна защищены собственным модальным диалогом «Сохранить и продолжить / Не сохранять / Отмена». Неудачное сохранение оставляет исходный проект и диалог. Импортированная копия считается несохранённой до явного сохранения в SQLite. Экспорт JSON не подтверждает успешность системного диалога загрузки и не снимает этот статус автоматически.

Перехват закрытия работает через Tauri onCloseRequested, с разрешением close/destroy только для главного окна. Нативный smoke test проверяет и отмену закрытия с грязными данными, и обычное закрытие чистой копии. Принудительное завершение процесса/отключение питания не может быть предотвращено этим диалогом.

## Границы
