> Актуальная компоновка — классическое CAD/CAE-окно: верхняя панель инструментов, слева дерево и свойства, справа постоянное рабочее поле, снизу раскрываемые результаты. # Первый настольный рабочий процесс

Это ограниченный математический инструмент, а не готовый нормативный MVP. Текущая версия использует вручную заданное эффективное линейное сечение. Никакие нормативные таблицы или тексты публикаций в приложение не включены.

## Запуск одним файлом

Из корня проекта запустить `start.bat` двойным щелчком или из CMD/PowerShell (`.\start.bat`). Скрипт сам перейдёт в apps/desktop, проверит Node.js 24+ / npm и Cargo, при первом запуске или изменении package-lock.json выполнит npm ci и запустит Tauri dev. Путь к проекту может содержать пробелы. Первая Rust-сборка занимает несколько минут; окно консоли нужно оставить открытым.

Rust, C++ Build Tools, Windows SDK и WebView2 устанавливаются отдельно. При ошибке скрипт оставляет сообщение в открытой консоли и возвращает ненулевой код. Зависимости определяются по SHA-256 lockfile; локальная отметка хранится только в игнорируемом node_modules.

## Windows 10/11 x64

Установить Node.js 24, Rust через rustup, Microsoft C++ Build Tools с Windows SDK и WebView2 Runtime по [требованиям Tauri 2](https://v2.tauri.app/start/prerequisites/). Из корня checkout:

```powershell
rustup toolchain install 1.99.1 --profile minimal --component rustfmt --component clippy
cargo fmt --all -- --check
cargo clippy --locked -p weld-core -p weld-application --all-targets -- -D warnings
cargo test --locked -p weld-core -p weld-application
cd apps/desktop
npm ci --no-audit --no-fund
npm test
npm run tauri dev
```

Для выпуска самостоятельного исполняемого файла (без установщика):

```powershell
# Рабочий каталог: apps/desktop
npm run tauri build -- --no-bundle --ci
# Результат: ../../target/release/weld-desktop.exe
```

Сборка выполняет TypeScript-проверку и Vite production build через beforeBuildCommand. Backend собирается с Cargo.lock; frontend — с package-lock.json. Linux/macOS приложение на этом этапе не поддерживается и не испытывается. Форматирование исходников и создание lockfiles не являются испытанием приложения на другой платформе.

## Рабочий сценарий

1. Ввести координаты начала/конца каждого прямого участка в mm и эффективную ширину a в mm. Это не катет и не автоматически определённое горло лазерного шва. Добавить/удалить участки можно в таблице. На схеме можно выбрать участок, перетаскивать его концы или перемещать сфокусированный конец стрелками (1 mm, Shift — 10 mm). Escape отменяет перетаскивание с восстановлением исходного результата. При законченном изменении результат требуется пересчитать. ПКМ открывает собственные команды редактора.
2. Задать Fx/Fy/Fz в N и свободную пару Mx/My/Mz в N·mm. По умолчанию сила приложена в центре сечения. Для произвольной точки отключить флажок и задать координаты P в mm.
3. Нажать «Рассчитать». Rust вычисляет геометрию и переносит момент к центру сечения. При точно нулевом результирующем моменте возвращает номинальные компоненты F/A. При ненулевых моментах рассчитывается аффинное номинальное распределение изгиба/полярного кручения. При вырожденном или плохо обусловленном сечении для изгиба напряжения отсутствуют и показывается причина. Малые моменты не отбрасываются по произвольному допуску.
4. Проверка прочности всегда недоступна. Математический результат имеет отдельный статус not independently validated. Нет допускаемых напряжений, safety margin, pass/fail, ГОСТ-геометрии или подтверждения качества изготовления.
5. «Сохранить ревизию» записывает новый неизменяемый снимок в SQLite. Повторное сохранение не перезаписывает предыдущую запись. «Открыть ревизию» показывает последние 100 сохранений и открывает выбранный исходный результат без пересчёта.
6. При редактировании входа прежний результат удаляется из текущей рабочей копии. Escape во время drag восстанавливает исходный снимок; запоздавший ответ на промежуточные данные игнорируется. Сохранённая в SQLite ревизия остаётся неизменной. Для нового результата нажать «Рассчитать».
7. Импорт/экспорт JSON проходит через Rust-валидацию. Импортированные результаты являются внешними данными, не подтверждёнными расчётом этой сессии; интерфейс показывает предупреждение. Приложение не проверяет подлинность стороннего JSON криптографически.

Текущая рабочая копия сохраняется явно. При создании/открытии/импорте другого проекта или закрытии окна несохранённые изменения защищены собственным диалогом. Если сохранение завершилось ошибкой, исходный проект остаётся открыт.

## Хранилище и формат

База `projects.sqlite` находится в каталоге app data, который Tauri определяет для identifier `ru.posmis.weldengineering` (в Windows обычно под `%APPDATA%`). Абсолютный путь не приходит с frontend. Backend не предоставляет произвольного доступа к файловой системе или shell.

Таблица project_revisions содержит UUID, название, Unix timestamp в миллисекундах и JSON документа. SQLite user_version=2 (таблица настроек добавлена без изменения документов ревизий). Более новая схема отклоняется без изменения базы. Версия проекта и запроса schema_version=1. Поля input_snapshot, engine_version и method_id сохраняются вместе с результатом. Открытие валидирует структуру и согласованность, но не заменяет исходный результат повторным расчётом. Плавающие числа сериализуются с поддержкой float_roundtrip.

Ограничения: 1–256 участков, до 200 Unicode-символов в названии, JSON до 1 МиБ, только конечные числа. Нулевые длины и неположительные ширины отклоняются. Геометрия в application service запрещает перекрытия и пересечения внутри участков, но разрешает общие концы. Линейные элементы не являются геометрическим объединением конечных полос ширины a.

Пересечения проверяются точными рациональными детерминантами для исходных конечных двоичных координат (num-rational). Здесь нет произвольного геометрического допуска, который мог бы пропустить почти параллельное пересечение. Пары с непересекающимися bounding boxes отбрасываются до этой проверки. Сами интегральные свойства по-прежнему вычисляются в f64; рациональная проверка топологии не означает произвольную точность всех инженерных результатов.

## Локализация и интерфейс

Русский язык по умолчанию, переключение RU/EN, светлая/тёмная темы. Строки и коды ошибок отделены в src/locales. Числовые поля принимают десятичную точку или запятую; пустое поле не превращается в ноль. Frontend делает только редактирование и преобразование координат для SVG; площади, центры, моменты и напряжения вычисляются Rust.

Пока нет интерактивного сечения стандартного соединения, векторов силы на схеме, отчётов PDF, каталога материалов, REST API, оптимизации и нормативных сопротивлений. Следующая итерация должна расширять этот реальный путь, а не добавлять демонстрационные результаты.


## Меню и инструменты разработчика

Обычное браузерное меню WebView2 отключено в dev и release. На схеме доступны команды приложения, в текстовых полях работают обычные клавиатурные операции копирования/вставки. По умолчанию инспектор не открывается.

Для явной диагностики интерфейса разработчиком в **debug/dev** можно установить WELD_DEVTOOLS=1 перед запуском start.bat: панель открывается автоматически. Например, в PowerShell:

```powershell

.\start.bat
Remove-Item Env:WELD_DEVTOOLS
```

В release EXE эта переменная не включает инструменты разработчика. Сам BAT не включает этот режим.

## Шаг, привязки и перенос шва

В шапке «Настройки приложения»: положительный шаг перемещения в mm, шаг сетки, радиус захвата 1–64 CSS px; отдельные переключатели сетки, концов, середин других швов и осей X/Y. По умолчанию шаг 1 mm, привязка к концам включена. Настройки сохраняются в локальной SQLite отдельно от проектов и действуют после перезапуска.

Тяните линию для переноса шва целиком или кружок для перемещения конца. Стрелки на выбранном элементе используют заданный шаг, Shift умножает его на 10; клавиатурное движение обходится без привязок. При перетаскивании Alt временно отключает привязки. Escape отменяет жест и восстанавливает исходный результат, если остальные расчётные данные не изменялись. Шаг округляет смещение от начала жеста, сохраняя исходные дробные координаты. Привязки имеют приоритет над шагом: ближайший конец/середина другого шва, затем оси, затем сетка. Шов при переносе сохраняет вектор и эффективную ширину. Ввод координат в таблице остаётся точным и не округляется.

Камера после перемещения остаётся на месте; «Вписать схему» заново показывает все участки. При плотной сетке отображаются укрупнённые линии с интервалом не менее 12 единиц SVG; фактический шаг привязки не меняется. Привязки не разрезают и не объединяют участки: геометрию по-прежнему проверяет Rust при расчёте. Изменение настроек само по себе не изменяет проект и сохранённый расчёт.

## История и навигация

«Отменить» / «Повторить» и Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z восстанавливают предыдущие данные, выделение и связанный расчётный снимок. Перетаскивание целого участка или конца — одна операция; набор в одном поле объединяется до смены фокуса. В текстовых полях сочетания остаются у встроенного редактора текста; для отмены операции проекта используйте кнопки. История ограничена 100 действиями и хранится только в памяти. Новый/открытый/импортированный проект начинает новую историю. После отмены новая правка очищает ветку повтора; Escape при перетаскивании сохраняет прежнюю ветку повтора. Undo не переписывает ревизии SQLite и не выполняет расчёт заново. Возврат к сохранённому снимку восстанавливает чистое состояние.

Колесо масштабирует схему вокруг курсора; «+» / «−» — вокруг центра вида. Диапазон 1–10000% относительно вписанного вида. Средняя кнопка мыши или включённое «Панорамирование» перемещают камеру. Escape отменяет текущий жест панорамирования; повторный Escape выключает режим. «Вписать схему» возвращает все участки в кадр. Камера не входит в проект, не удаляет результат и не создаёт записи в истории. Во время переноса шва масштабирование и команды истории недоступны.

## Распределение при моментах

В результатах доступны диапазон σz, максимум |τ|, выбор участка и компоненты, график вдоль s/L и таблица обоих концов. Все напряжения и экстремумы приходят из Rust. Произведение инерции Ixy учитывается. [Модель, знаки, численные ограничения и эталоны](nominal-bending-torsion.md). Перенос силы из произвольной точки учитывает все компоненты r×F. Это номинальные компоненты на заданных эффективных элементах, без оценки прочности и локальных концентраций. Старые результаты F/A и unsupported loading сохраняются при открытии; новый расчёт выполняется только по команде пользователя.

## Классическое CAD/CAE-окно

Обычное окно Windows открывается развёрнутым, с системной рамкой и кнопками управления. Верхняя панель содержит создание/открытие/сохранение, импорт/экспорт, undo/redo, добавление шва, расчёт и управление результатами. Нативный fullscreen и отдельные переходы к форме расчёта удалены.

Слева дерево «Модель и расчёт»: ветка швов с отдельными S1…Sn, нагрузки и результаты. Выбор шва в дереве или на схеме показывает его координаты и эффективную ширину в свойствах. Выбор нагрузок показывает Fx/Fy/Fz, Mx/My/Mz и точку приложения. Дерево поддерживает стрелки, Home/End и раскрытие ветки. Добавление/удаление, свойства и выделение используют одну входную модель.

Справа постоянно остаётся рабочее поле; масштаб/панорамирование/привязки и редактирование действуют как прежде. Расчёт автоматически открывает панель результатов под рабочим полем. Она имеет вкладки напряжений и геометрии, закрывается крестиком и открывается из дерева или панели инструментов без повторного расчёта. Результат при изменении входа инвалидируется внутри той же панели, без её автоматического закрытия.

Границы левой панели и нижних результатов перемещаются мышью и стрелками с клавиатуры. Камера адаптируется к размерам, проект от этого не меняется. Сообщения и признак сохранения находятся в строке состояния фиксированной высоты, чтобы не менять поле посреди переноса. Схемы JSON, SQLite и расчётные методы не изменены.

## Новые расчётные операции и отчёты

В дереве выберите «Нагрузки», чтобы создать/выбрать независимый случай и изменить его силы/моменты. «Рассчитать все» обрабатывает набор; раскрываемая сводка находится в нижней панели. Изменение геометрии инвалидирует весь набор. [Случаи и сводка](load-cases.md).

В свойствах шва раскройте «Прерывистый шов», задайте длину/шаг/число и замените отрезок реальными отдельными участками. Это геометрическая операция без нормативных рекомендаций, отменяемая одним Undo. [Подробности](intermittent-welds.md).

«Отчёт PDF» сохраняет документ через окно Windows и показывает фактический путь в статусе. Внутри — геометрия, нагрузки, формулы, результаты/предупреждения и вложенный исходный JSON. Можно выгрузить нерассчитанный проект: отсутствие результатов будет указано. [Отчёт и ограничения](pdf-reports.md).

`start-api.bat` отдельно запускает локальный API; desktop этого не делает. [API/OpenAPI](api-reference.md), [C# и будущий Inventor adapter](inventor-integration.md). Полный перечень незакрытых этапов — [completion-status.md](completion-status.md).

## Нагрузки и карта в рабочем поле

«Вид» переключает геометрию и номинальные σz/τx/τy. «F / M» показывает/скрывает заданные нагрузки; «Швы + точка P» вписывает вынесенную точку приложения. Шкала не является проверкой прочности. Изменение исходных данных немедленно снимает карту старого результата. Подробности/границы — [viewport-results.md](viewport-results.md).

### Группа по размерам

«Шаблон группы» в верхней панели: выберите прямоугольник, параллельные, П- или Г-образную схему; задайте W/H, эффективную ширину a и центр габарита X/Y. Дождитесь предпросмотра Rust и нажмите «Заменить геометрию». Нагрузочные случаи сохраняются, результаты сбрасываются; новая группа вписывается в поле. Один Undo возвращает прежнюю геометрию и снимки результатов. Это не выбор типа соединения по ГОСТ. [Параметры, ограничения и проверка](geometry-templates.md).

В настройках «Показывать координатную сетку» включает только её отображение; «Привязка к сетке» независимо управляет перемещением. Шаг задаётся полем «Шаг сетки, mm». Видимость сохраняется между запусками. Оси XY и блок заданных нагрузок расположены вертикально в общем углу viewport, с промежутком; отключение F/M оставляет оси видимыми.

### Перенос, поворот и отражение группы

«Преобразовать» в верхней панели открывает параметры операции для всей группы и общий предпросмотр исходных/новых участков. Опорная точка задаётся явно, положительный угол направлен против часовой стрелки. Нагрузки и заданная P остаются в глобальных координатах; после применения все случаи требуют расчёта. Один Undo восстанавливает исходное состояние. [Контракт и ограничения](geometry-transform.md).

### Раскрывающееся дерево и отдельные свойства

Ветки «Сварные швы»/«Нагрузки» раскрываются. ПКМ в дереве → «Добавить участок» или «Добавить силу»; новый элемент появляется в списке и выбирается. У силы собственные Fx/Fy/Fz и C/P, несколько сил действуют одновременно. Свободный момент M1 редактируется отдельным узлом. Свойства находятся в самостоятельном столбце рядом с деревом; два вертикальных разделителя меняют ширину дерева/свойств и оставшуюся ширину viewport. Работают мышь и стрелки; результаты остаются снизу. [Контракт и ограничения](tree-and-simultaneous-forces.md).

### Копирование и удаление узла

ПКМ на конкретном шве/силе → «Копировать участок»/«Копировать силу» или удалить. Сила копируется с компонентами/P как ещё одна одновременно действующая сила; шов — через окно преобразования с проверкой всей группы. Копия шва добавляется последней, исходные остаются. Каждое действие отменяется одним Undo вместе с результатами. [Подробности](tree-item-actions.md).
