# Преобразование группы швов

«Преобразовать» в верхней панели работает со всеми явными участками. Поддерживаются перенос ΔX/ΔY, поворот на угол вокруг заданной точки и отражение относительно линии, параллельной X или Y и проходящей через заданную точку. Для X-отражения меняется Y, для Y-отражения — X. Положительный угол — против часовой стрелки в XY. Опорная точка вводится явно; её нельзя считать центром эффективного сечения без расчёта.

Rust возвращает предварительный результат. В окне пунктиром показана исходная группа, сплошными линиями — предложенная, в общем масштабе. После правки параметров прежний preview недоступен для применения; поздние ответы игнорируются. Escape/«Отмена»/нативное закрытие отменяют только окно предварительного просмотра. Применение меняет все координаты, сохраняет количество, порядок и эффективную ширину участков. Новая схема вписывается в поле, нижняя панель старого результата закрывается.

Силы F, свободные моменты M и заданная точка P всех случаев **остаются в глобальных координатах**. Это изменение геометрии относительно нагрузки, а не поворот всей физической задачи. Номинальные результаты всех случаев сбрасываются; один Undo возвращает прежние геометрию и результаты. Форматы проектов/SQLite не меняются. Полный проект с незаполненными нагрузками в генератор не сериализуется.

`geometry_transform::transform(GeometryTransformRequest)` и Tauri `transform_group(request)` принимают schema_version=1, segments и transform:

- `{"kind":"translate","delta_mm":[25,-10]}`;
- `{"kind":"rotate","origin_mm":[0,0],"angle_deg":90}`;
- `{"kind":"mirror","origin_mm":[0,0],"axis":"x"}`.

Ответ: schema_version=1, segments. REST POST `/api/v1/geometry/transform` вызывает тот же сервис, имеет собственные request/result схемы OpenAPI и общие авторизацию/лимиты. Неизвестные поля/версии и неконечные параметры отклоняются. Входная и итоговая геометрия проходят общий exact intersection validator. Для кратных 90° коэффициенты точные 0/±1; для остальных углов используется f64 sin/cos. Проверка относительного сохранения длины каждого участка (√ε) отвергает существенную потерю точности, схлопывание или переполнение, а не исправляет геометрию молча. Это не гарантия произвольной точности при больших смещениях.

Пройдены аналитические Rust-тесты переносов центра/инерции, смены знака Ixy при отражении/повороте 90°, обратного поворота 37°, HTTP/OpenAPI и frontend проверки позднего preview/ошибок/сохранности глобальной точки P. Windows native сценарий проходит три операции, расчёт 2/2 и Undo после каждой.
