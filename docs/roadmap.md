# Дорожная карта и условия продолжения

Актуальная матрица: [completion-status.md](completion-status.md), подробные критерии: [scope-and-acceptance.md](scope-and-acceptance.md). Номера этапов сохранены из исходных требований; интеграционная инфраструктура развивается параллельно расчётным методам.

0. Продолжить официальный реестр статусов/поправок, сравнение методов с полными легальными источниками и независимый инженерный обзор. Полного нормативного метода машинных сварных соединений пока нет. Источники/результаты поиска: standards-research.md, research-continuation.md. Не восстанавливать коэффициенты по оглавлениям или случайным калькуляторам.
1. Существующие Rust/GUI/SQLite/JSON/PDF довести до нормативного MVP только после подтверждения статической методики, геометрии, материалов и независимых примеров. Windows CI автоматизирован; это техническая проверка, не аттестация инженерной методики. До подтверждения критериев автоматический подбор не выдаёт допустимое решение.
2. Использовать реализованные номинальные изгиб/кручение, r×F, случаи/сводку и явные прерывистые участки как ограниченную математическую основу. Далее — проверенные сочетания, материалы, критерии и сравнение/оптимизация, с отказами при недостаточных данных.
3. Производственные ограничения, расширенные EN 1011, процессы, несовершенства и контроль требуют проверенных источников и отдельных эталонов. Интерфейсные поля сами по себе этот этап не закрывают.
4. Усталость, давление, герметичность и специализированные методы — отдельные модели и области применимости. Статическое computed никогда не означает fatigue/pressure/quality acceptance.
5. Действуют opt-in REST/OpenAPI, примеры Windows/C# и Inventor guide. Новые endpoints появляются вместе с проверенными сервисными методами, а не с фиктивными успехами. Add-in сейчас не создавать.

Для завершения каждого модуля нужны: исходные данные и происхождение; версия метода; границы применимости; математическая и независимая инженерная проверка; весь путь GUI/service/отчёт; ошибочные входы и явная неполнота; актуальная Windows-проверка. Установщик проверен на windows-2022 с сохранением проектов после удаления. Отдельно остаются Windows 10/11 acceptance, подпись и политика обновления. Публикация GitHub release требует отдельного указания; push в main и CI не равны выпуску сертифицированного продукта.
