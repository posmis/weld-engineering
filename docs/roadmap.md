# Дорожная карта и условия продолжения

0. Архитектура и математические выводы записаны. Завершить официальный реестр статусов/поправок, сравнение методов с полными источниками и независимый инженерный обзор. Без этого фаза 0 не завершена.
1. Выполнить Windows проверки core, исправить обнаруженные дефекты, зафиксировать toolchain/lockfiles. Реализовать serializable service contracts, SQLite и versioned snapshots. После утверждения методики добавить статическую прочность с эталонами. Затем Tauri 2/React, русский UI и английские ресурсы, настоящие диаграммы, PDF и интеграционные проверки. Не маркировать геометрическую основу как функциональный прочностной MVP.
2. Развить группы/нагрузки и ограниченную оптимизацию после верификации критериев.
3. Добавить производственные/качественные ограничения и лазерные процессы по проверенным источникам.
4. Усталость, давление, приёмочные проверки герметичности — отдельные методики.
5. REST/OpenAPI и C# Inventor integration guide с проверенными схемами и совместимостью.

Внешние условия: официальные документы/статусы и доступный Windows runner. Исходный статус до первого push: публикация, push и утверждение инженерной методики не выполнялись. Последующую отправку кода проверять по GitHub; она не означает утверждение методики.
