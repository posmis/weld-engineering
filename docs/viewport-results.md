# Нагрузки и номинальная карта на схеме

В верхней строке рабочего поля переключатель «Вид» выбирает геометрию либо σz, τx, τy в MPa. Карта окрашивает реальные участки по сохранённым Rust-значениям на концах. Для F/A каждый участок имеет постоянный цвет; для аффинного распределения цвет меняется вдоль участка. Между отрицательным и положительным значением добавлена точная нейтральная точка: интерполяция цветов не создаёт ложного фиолетового значения в нуле.

Шкала симметрична относительно нуля: синий — отрицательная компонента, светлый — ноль, красный — положительная. Её предел — наибольшее абсолютное значение отображаемых конечных компонент; это масштаб изображения, а не допускаемое напряжение. Числа выбранного участка показаны под шкалой в порядке начало/конец. Нулевая нагрузка даёт нейтральный цвет без деления на ноль. Нормирование цвета выполнено без разности огромных исходных значений, чтобы избежать переполнения.

Это **номинальные компоненты**, не эквивалентные напряжения, не локальные throat stresses и не показатель использования прочности. Нормативный pass/fail по цвету не определяется. При неподдерживаемом нагружении, отсутствии результата или несовпадении input_snapshot с рабочими данными карта не выдаётся. Правка геометрии/нагрузок сразу убирает старую карту; после явного нового расчёта применяется новое распределение. −0/+0 нормализуются при сравнении с JSON IPC как одна физическая величина.

«F / M» включает слой нагрузок. Численно всегда показаны Fx/Fy/Fz, свободные Mx/My/Mz и точка приложения. На схеме: Fxy — направление проекции силы; Fz — точка в круге для +Z к наблюдателю либо крест для −Z; Mz — дуга против часовой стрелки для положительного момента в правой XY-системе. Mx/My пока представлены численно, отдельные пространственные дуги для них не рисуются. Длины символов условные, не пропорциональны силе/моменту. Символ Fz смещён с соединительной линией для читаемости, сама точка приложения не меняется.

Для заданной точки P используется её XY-проекция, Pz остаётся в численном блоке и исходной задаче. Если она вне вида, показано сообщение. «Швы + точка P» вписывает геометрию и P, обычное «Вписать схему» возвращает масштаб только швов. Для центральной силы Rust-центр доступен после расчёта геометрии; до него центр не подменяется средним концов или центром экрана. Невалидные/непредставимые размеры не превращаются в фиктивный результат.

Вид/масштаб/видимость нагрузок не входят в проект, не меняют признак сохранения, не вызывают пересчёт и не изменяют Undo. Выделение и перетаскивание швов доступны поверх карты. При редактировании геометрии у всех случаев удаляются рабочие результаты: сводка 0/N показывается сразу без вызова Rust на каждый pointermove. Сводки существующих снимков запрашиваются после 250 ms паузы; устаревший ответ не подменяет новый проект. Во время операции кнопки перехода к определяющим случаям блокируются вместе с остальным вводом.

Подпись объединена, блок нагрузок уплотнён, подпись Mz разведена с номером шва. Повторный полный прогон ещё ожидается. Методики ядра, DTO/SQLite и PDF не изменены. Предыдущая версия ab54f56 проверена в Windows run 41907826120: NSIS install/uninstall с сохранением SQLite, 51 Rust/API, 44 frontend ×3, OpenAPI/C# и независимый PDF parser — success.

Числа в легенде/нагрузочном блоке округлены до семи значащих цифр; очень большие и малые значения записываются научной нотацией. Точные исходные данные доступны в свойствах и JSON.

При автоматическом вписывании карты справа оставляется место для шкалы; блок нагрузок занимает нижний край. Камера хранит сдвиг в том же View, который захватывается жестом, поэтому снятие результата при начале правки не меняет преобразование координат посреди переноса. Явно заданные пользователем zoom/pan сохраняются до команды вписывания.
