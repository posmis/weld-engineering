# Нагрузочные случаи, прерывистые участки, PDF и локальная интеграция

Разработка 2026-11-04 продолжает полный план, не объявляя нормативные модули завершёнными.

## Реализованный объём

- До 32 независимых нагрузочных случаев с общей геометрией; свои нагрузки/точки/снимки каждого случая. Пакетный Rust-расчёт, ошибки отдельных случаев, полная/частичная сводка σz min/max и |τ| max с определяющим случаем/участком/концом. Сочетания и fatigue-спектр не выводятся из списка автоматически.
- Прерывистый шов как явные отдельные элементы вместо выбранного отрезка. Длина/шаг/число задаются инженером, геометрия проверяется в Rust. Промежутки не участвуют в сечении. Один Undo восстанавливает модель и результаты всех случаев.
- PDF с кириллицей, схемой, исходными данными, формулами/подстановками, результатами/версиями/предупреждениями и исходным JSON-вложением. Нативный save dialog Windows, фактический путь в статусе, отмена без изменений проекта. Отчёт всегда сообщает отсутствие нормативной оценки прочности.
- Отдельный weld-api.exe/start-api.bat: loopback, токен каждого запуска, ограничения тела/workers/ожидания, те же Rust operations. OpenAPI 3.1, настоящая HTTP-проверка схем и самостоятельный C# client. Inventor guide определяет единицы/преобразования/ревизии; add-in не создаётся.
- Во время переноса геометрии сторонние изменения форм заблокированы, Esc/Undo сохраняют согласованность всего набора. Компоновка остаётся классическим CAD/CAE-окном.

Подробности: [load-cases.md](load-cases.md), [intermittent-welds.md](intermittent-welds.md), [pdf-reports.md](pdf-reports.md), [api-reference.md](api-reference.md).

## Доказательства проверки

Нагрузочные случаи отдельно проверены: 4a3d3b6, Windows run 41899254686 — success. Последовательные прогоны выявили и исправили отсутствие @types/node, большой Err в HTTP adapter, удерживаемый Windows handle токен-файла и необходимость подтверждения filename edit перед Save. Исходные тексты ГОСТов/книг в этих проверках и артефактах не использовались.

Итоговый Windows-прогон пока ожидается; результат не объявляется пройденным до завершения.

## Что этот этап не завершает

Нормативная статическая прочность, нормативная геометрия/материалы/коэффициенты, автоматический подбор, усталость, давление/герметичность, WPS/WPQR и технологическая/лазерная приёмка остаются недоступными. Нет независимой инженерной валидации, испытаний на отдельных Windows 10/11 машинах, installer/подписи/обновления. Полная матрица — [completion-status.md](completion-status.md). Наличие API или отчёта не меняет этих статусов.
