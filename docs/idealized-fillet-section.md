# Расчётное сечение углового шва по двум катетам

Первый расчётный блок после переноса UI в конец плана. Статус реализации: [Windows run 42057308788 — SUCCESS](https://github.com/posmis/weld-engineering/actions/runs/42057308788), исходники `ff5daec46db12909d9f7bdecceabc2f4f9ec1957`. Это математическая геометрия, **не нормативная геометрия ГОСТ и не прочностная проверка**.

## Модель и собственный вывод

Предполагается прямоугольное треугольное сечение: корень под 90°, катеты k1/k2, прямая грань между концами. Учет дополнительного провара, выпуклости/вогнутости, дефектов и коэффициентов процесса отсутствует. Умножение высоты на длину используется только в прежней номинальной линейной модели; локальные напряжения на наклонной плоскости горла не вычисляются.

Из площади одного треугольника k1·k2/2 = c·a/2 и c=√(k1²+k2²) следует a=k1·k2/√(k1²+k2²). Для равных катетов a=k/√2. Реализация масштабирована: low/hypot(1,low/high), что исключает переполнение произведения катетов и длины гипотенузы. Неположительные/неконечные размеры, схлопывание и значимая потеря точности в субнормальном диапазоне отклоняются. Никакой нормативный минимум/максимум катета не подставляется.

Независимый эталон: треугольник 3–4–5 mm имеет высоту 12/5=2,4 mm. На участке 100 mm получается номинальная площадь 240 mm²; при центральной Fz=600 N — σz=2,5 MPa. Это равновесие принятой идеализации, не подтверждение несущей способности сварного соединения.

## Данные и сервис

`weld_core::section::right_angle_fillet_throat` выполняет геометрию; application `sections::derive` принимает schema_version=1 и model={kind:idealized_right_angle_fillet,leg_1_mm,leg_2_mm}. Ответ содержит model, effective_width_mm, method_id=right-angle-fillet-altitude-v1, status=idealized_geometry. Tauri `derive_section` и REST POST `/api/v1/sections/derive` вызывают тот же код. OpenAPI описывает request/result.

SegmentInput получил optional section с исходными катетами. Старые данные без поля читаются и сериализуются как раньше. Сохранённая эффективная ширина должна совпадать с выведенной в пределах 8ε относительной погрешности; иначе section_width_mismatch. В расчёте используется выведенное a. Параметры сохраняются в input_snapshot, JSON, SQLite, копиях и прерывистых участках. Старый строгий reader не прочитает новый section — нужен актуальный клиент. При наличии модели результат получает предупреждение idealized_section_geometry; strength_status по-прежнему unsupported_calculation, validation_status — not_independently_validated.

В существующих свойствах шва раскрыть «Модель сечения», ввести катеты и нажать «Рассчитать и применить сечение». Начальные 3/3 mm — редактируемый пример, не рекомендация. a становится доступным только для чтения. Явная команда «Задать ширину вручную» снимает модель, сохраняя текущее a; ручной ввод снова доступен. Undo восстанавливает модель/результаты. Пока Rust отвечает, изменение адресуемого шва отменяет применение ответа; старый ответ не перезаписывает новые данные. Незаполненные нагрузки не сериализуются в сервис сечения и не превращаются в ноль.

PDF перечисляет катеты, a и геометрические допущения, метод и отсутствие проверки соответствия ГОСТ. Вложенный исходный JSON содержит модель. Изменение сечения инвалидирует результаты всех случаев, как изменение геометрии.

## Нормативная граница и продолжение

Локально доступны пользовательские ГОСТ 5264-80 и 14771-76, библиографические записи/хеши — data/standards/uploaded-sources.json. Параметры и таблицы этих документов этим модулем не импортированы, их полный текст не публикуется. ГОСТ 5264-80 относится к типам, конструктивным элементам и размерам; наличие геометрического стандарта не разрешает универсальную оценку прочности. Статусы content_pending/normative_calculation_enabled=false в реестре не повышаются данным изменением.

Предстоит отдельно реализовать проверенные типы соединений, применимость к процессу/толщинам/редакции, локальную нормативную проверку размеров, материалы/сопротивления и критерий прочности. Модель прямого угла не применяется автоматически к лазеру, произвольному углу, стыку или полному/частичному провару.
