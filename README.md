# Weld Engineering

Система проектирования сварных соединений для машиностроения. Целевая платформа: Windows 10/11 x64.

**Состояние:** документация фазы 0 и начальная математическая основа. Приложение, нормативный расчёт прочности и функциональный MVP ещё не реализованы. Действующий статус трёх ГОСТ подтверждён официальным каталогом; нормативные параметры и полный текст поправки ещё не проверены. Результаты основы не являются проверкой безопасности соединения.

Испытания подготовлены, но в исходной Linux-среде не выполнялись по ограничению целевой платформы. Windows CI запускается после размещения файлов на GitHub; результат CI пока неизвестен.
