# Weld Engineering

Система проектирования сварных соединений для машиностроения. Целевая платформа: Windows 10/11 x64.

[Проверенная Windows-сборка с установщиком](https://github.com/posmis/weld-engineering/actions/runs/42092433925/artifacts/13446517142) · [результаты проверки](docs/testing.md). Артефакт хранится 7 дней.

**Приоритет:** переработка UI отложена до конца основных расчётных этапов. Добавлено [идеализированное сечение по двум катетам](docs/idealized-fillet-section.md), с сохранением исходных размеров; это не нормативная геометрия ГОСТ.

**Состояние:** Windows CAD/CAE-приложение Tauri 2/React с независимым Rust-сервисом, SQLite/JSON, номинальными F/A, изгибом и полярным кручением. Раскрывающееся дерево поддерживает добавление, копирование и удаление швов/сил через ПКМ, свойства представлены инженерными таблицами в отдельном столбце. Ширины столбцов и высота результатов сохраняются; есть восстановление стандартной раскладки. Несколько сил действуют одновременно, каждая со своей точкой приложения. В рабочем поле доступны нагрузки и карты номинальных σz/τx/τy с цветовой шкалой. Есть перенос, поворот и зеркальное отражение всей группы с предварительным просмотром. Есть построение прямоугольной, параллельной, П- и Г-образной группы по размерам с предпросмотром и Undo. Добавлена эквивалентная нагрузка от массы и поступательного ускорения F=m(g−a), с сохранением исходных m/g/a и переносом момента от центра масс. Добавлены независимые нагрузочные случаи, пользовательские сочетания с явными коэффициентами/снимками источников и сводка, прерывистые участки, русскоязычный PDF с исходным JSON, отдельный loopback REST/OpenAPI и C# пример интеграции. Полный продукт ещё не завершён: нормативная прочность, материалы, подбор, усталость и технологические/специальные проверки требуют подтверждённых методов и инженерной валидации. [Точное состояние всех этапов](docs/completion-status.md).
